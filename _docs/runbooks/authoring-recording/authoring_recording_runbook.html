Arenic Authoring and Recording Runbook

A practical onboarding guide for designers building Normal, Heroic, and Mythic boss encounters with the native authoring tool.

AudienceEncounter designers and content authors
ToolNative author build: just author
OutputVersioned encounter stacks in assets/encounters
Current ability caveat. Not all boss and hero abilities exist yet. Today, boss slots can record, but the live loadout is still placeholder-heavy: slot 1 resolves to Holy Nova and slots 2-4 may be inert until their abilities land. Build the timing, movement, tile pressure, and layer structure now; swap in final abilities later.

1. Mental Model

Author mode is a native-only build that layers encounter content on top of the normal game simulation. Each arena and difficulty owns a draft layer stack. Playback folds that stack into the normal two-minute, 60 Hz timeline.

  • Cycle length: 120 seconds, 7,200 ticks. Every movement, ability, tile keyframe, and effect key lands on an integer tick.
  • Difficulty ownership: Normal, Heroic, and Mythic are separate authoring targets. Use D to cycle between them.
  • Draft vs published: edits stay in memory until W publishes the focused arena's stack.
  • Layer conflict rule: top tile layer wins when two layers claim the same cell at the same tick.
  • Rollback: delete the newest layers.vNNNN.ron file, then restart/reload. Git history is the second level of undo.

2. Launch and Pick the Assignment

  1. Run just author. Do not use the web app for authoring; author systems are excluded from WASM builds.
  2. Use [ / ] to focus the arena you are building.
  3. Use D to choose Normal, Heroic, or Mythic. If the tool warns about dirty edits, publish with W or quit/reopen to discard the in-memory draft.
  4. Use P to zoom into the focused arena for detailed placement.

4. Record Boss and Minion Timelines

  1. Focus a combat arena with [ / ], then zoom with P.
  2. Press B until the boss or target minion is selected.
  3. Rehearse movement with arrows and slot casts with 1-4. Hold an arrow while pressing a slot to record an aim direction for abilities that use it later.
  4. Press R to start the three-second countdown. Capture runs from 0:00 across the two-minute cycle.
  5. Press R again to stop early, then choose Commit, Keep recording, or Discard.
  6. Only publish with W when the take should become the next versioned encounter file.

7. Designer Assignment: Build Three Difficulties

Each assigned boss should receive a Normal, Heroic, and Mythic pass. Because final abilities are incomplete, focus on readable timing, repeatable movement, tile pressure, and layer structure.

Normal

  • Create a readable two-minute boss movement loop with clear safe windows.
  • Use slot 1 where you need a placeholder cast. Do not depend on missing slots 2-4 for shipped difficulty.
  • Add at least one simple tile hazard or phase marker if it teaches the encounter pattern.
  • Publish only after watching a full clean cycle with F5.

Heroic

  • Start from the Normal mental model, then add one additional pressure layer: tighter movement, a tile layer, or a minion layer.
  • Keep readability: designers and players should still be able to explain why a failure happened.
  • Use the same two-minute phase boundaries so later ability swaps remain aligned.

Mythic

  • Increase density through layering, not random input spam. The score should still be deterministic and inspectable.
  • Use separate tile layers for different concepts so top-layer conflict wins are intentional.
  • If adding minions, record each staff separately and verify the folded result from tick 0.

Done Criteria for Each Difficulty

  • The author chip has no dirty draft after publish.
  • The latest file exists under assets/encounters/<arena>/<difficulty>/layers.vNNNN.ron.
  • A full F5 watch-through starts correctly from tick 0.
  • Any placeholder ability expectations are noted in the encounter handoff.

8. Troubleshooting

SymptomFix
Author HUD missingUse just author. The web app and normal game build intentionally exclude author mode.
D will not switch difficultyYou have dirty draft edits. Publish with W or quit/reopen if the draft should be discarded.
Published the wrong takeDelete the newest layers.vNNNN.ron in that arena/difficulty directory, then restart/reload. Do not hand-edit another difficulty's folder.
Ability slot does nothingExpected for unfinished abilities. Record the timing anyway only if the future slot needs that timestamp.
Modal blocking inputsUse 1-9, focus arrows/Tab, Enter/Space, or Esc. World input is gated while modals are open.
Tile layer conflicts look wrongRemember top layer wins. Put overrides above broad base patterns.
